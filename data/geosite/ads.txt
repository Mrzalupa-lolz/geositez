# ============================================================================
#  ADS — главный список блокировки рекламы.
#  В роутинге:  "ext:custom-geosite.dat:ADS"  ->  outbound "block" (blackhole)
# ============================================================================
#
#  ПРИНЦИП: здесь только рекламные и трекерные ХОСТЫ. Доменов самих сервисов
#  (youtube.com, snapchat.com, soundcloud.com, vk.com) здесь нет и быть не должно —
#  иначе вместо рекламы отвалится сервис.
#
#  ЧЕСТНО О ТОМ, ЧТО НЕ БЛОКИРУЕТСЯ ПО ДОМЕНУ (и почему):
#   * YouTube pre-roll/mid-roll — видеореклама отдаётся с googlevideo.com, того же
#     хоста, что и само видео. Заблокируешь — умрёт YouTube целиком. Блокируются
#     только баннеры/трекеры (doubleclick, googlesyndication).
#   * Twitch — реклама вшита в тот же HLS-поток (SSAI, video-weaver). Домена нет,
#     блокировкой её не убрать. countess/spade.twitch.tv трогать не стоит: ломает
#     приложение, рекламу не убирает.
#     НО есть обход через роутинг, а не через блок: см. twitch-ads.txt (категория
#     TWITCH-ADS) — запрос токена и манифеста уводится в туннель, реклама не
#     подставляется, качество Source остаётся.
#   * Instagram / Facebook лента — реклама приходит тем же graph API, что и посты.
#   * Spotify аудио-реклама — тот же CDN, что и музыка. Режутся только трекеры.
#   * Telegram — спонсорские сообщения идут внутри MTProto, отдельного домена нет.
#  Всё, что реально режется по домену, ниже — по площадкам.
#
#  Плюс сюда автоматически подмешивается ADS-NETWORKS (~5300 доменов рекламных
#  сетей и мобильных ad-SDK из pgl.yoyo.org и AdGuard).
