# ============================================================================
#  TWITCH-ADS — домены, которые решают, покажет ли Twitch рекламу и в каком
#  качестве отдаст поток. Их — И ТОЛЬКО ИХ — гоним В ТУННЕЛЬ, сам Twitch
#  оставляем в DIRECT.
#
#  В роутинге:  "ext:custom-geosite.dat:TWITCH-ADS"  ->  outbound "proxy"
# ============================================================================
#
#  ПОЧЕМУ ЭТО РАБОТАЕТ. Реклама Twitch вшита в тот же HLS-поток (SSAI), своего
#  домена у рекламных сегментов нет — заблокировать её по домену нельзя.
#  Зато запросы, от гео которых зависит выдача, живут на РАЗНЫХ хостах, и их
#  можно развести по разным маршрутам:
#
#    * токен и манифест (gql / usher / playlist) — В ТУННЕЛЬ, с зарубежного IP
#      ноды. Оттуда прилетает полная лестница качества, включая Source; для
#      российского IP Twitch её срезает.
#    * видеосегменты (video-weaver, *.cloudfront.net) — НАПРЯМУЮ, с российского
#      IP. Рекламного инвентаря на РФ у Twitch нет, вставлять в поток нечего.
#
#  Итого: качество Source и без рекламы, плюс весь тяжёлый трафик видео идёт
#  мимо ноды. Ломается ЛЮБАЯ из половин: уведёшь сегменты в туннель — вернётся
#  реклама, оставишь манифест напрямую — вернётся резаное качество.
#
#  Это наблюдаемое поведение, а не документированный API Twitch: они могут
#  поменять логику в любой момент. Если реклама вернулась — первым делом
#  проверь порядок правил (ниже) и что сам twitch.tv всё ещё идёт в direct.
#
#  ПОРЯДОК ПРАВИЛ КРИТИЧЕН. gql.twitch.tv — поддомен twitch.tv, поэтому
#  правило TWITCH-ADS обязано стоять ВЫШЕ любого правила, уводящего twitch.tv
#  или зону .tv в direct (в т.ч. выше категории `twitch` у roscomvpn).
#  Стоит ниже — трюк молча перестаёт работать, и вернётся реклама.
#
#  ЦЕНА ВОПРОСА: через туннель пойдут ещё чат и API (gql) и превьюшки
#  (static-cdn) — это килобайты, на трафик ноды не влияет.
#
#  Список совпадает с категорией `twitch-ads` у hydraponique/roscomvpn-geosite.
#  Держим свою копию: это правило роутинга, а не инвентарь, и оно должно
#  работать, даже если их .dat на ноду не приехал.

gql.twitch.tv
usher.ttvnw.net
playlist.ttvnw.net
ads.twitch.tv
static-cdn.jtvnw.net
