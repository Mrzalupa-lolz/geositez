# ============================================================================
#  RU — российские сервисы для КЛИЕНТСКОГО роутинга (идут мимо VPN, DIRECT).
#  В роутинге:  "ext:custom-geosite.dat:RU"  ->  outbound "direct"
# ============================================================================
#
#  ЭТОТ СПИСОК — ТОЛЬКО ДОБАВКА. Массовый RU-роутинг делает roscomvpn-geoip
#  (~15 000 подсетей, пересборка ежедневно) и roscomvpn-geosite (whitelist,
#  category-ru). Здесь остаётся лишь то, чего у них нет — иначе мы вручную
#  ведём инвентарь, который кто-то уже ведёт машиной.
#
#  ЗДЕСЬ НЕТ доменов в зонах .ru / .su / .рф — они ловятся регулярками
#  на стороне клиента (их бессмысленно перечислять поштучно):
#
#      "regexp:.*\\.ru$", "regexp:.*\\.su$", "regexp:.*\\.xn--p1ai$"
#
#  Поэтому ниже — только российские сервисы в ЧУЖИХ зонах (.com/.net/.tv/.me),
#  которых нет ни в regexp, ни в списках roscomvpn.
#
#  Проверить, не появилось ли что-то из этого у них (и выкинуть отсюда):
#      go run ./tools/dupcheck   — про наши списки
#      сравнение с roscomvpn     — см. README, раздел «Разделение труда»
#
#  СОЗНАТЕЛЬНО УБРАНЫ ОТСЮДА:
#   * habr.com, habrastorage.org — у roscomvpn они в category-geoblock-ru:
#     Хабр режет функционал российским IP, ему место В ТУННЕЛЕ, а не в direct;
#   * mradx.net — рекламный CDN Mail.ru, живёт в ads.txt (BLOCK).
#     У roscomvpn он в whitelist (direct) — наше правило ADS должно стоять выше.
