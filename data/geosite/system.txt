# ============================================================================
#  SYSTEM — системные домены ОС: пуши, обновления, время, проверка сертификатов.
#  Идут МИМО VPN (сплит-роутинг -> direct).
#  В роутинге:  "ext:custom-geosite.dat:SYSTEM"  ->  outbound "direct"
# ============================================================================
#
#  Зачем мимо VPN:
#   * APNs/FCM держат постоянное TCP-соединение — гонять его через туннель
#     значит терять пуши при каждом реконнекте VPN;
#   * обновления ОС — это гигабайты, незачем жечь трафик ноды;
#   * OCSP/CRL через туннель = залипание на проверке сертификатов;
#   * NTP через прокси часто просто не работает (UDP).
